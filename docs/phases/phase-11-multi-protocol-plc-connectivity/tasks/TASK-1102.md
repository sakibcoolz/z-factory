# TASK-1102 — Multi-Protocol Edge Deployment JSON Contract

Status: **PLANNED**

Phase: **11 — Multi-Protocol PLC Connectivity**

## Objective

Version the Edge Deployment JSON so one schema can safely describe Modbus TCP or OPC UA PLC workers.

## Modbus block

Host, port, unit id, polling/timeout settings and explicit register/coil mappings.

## OPC UA block

Endpoint URL, security policy/mode, authentication reference, session/subscription timing and explicit NodeId mappings.

## Rules

- Exactly one protocol block is active per PLC deployment.
- Every exported tag has a stable logical id/name, type, direction/access and protocol mapping.
- Writable entries are limited to command/setpoint roles.
- Credentials/private keys are referenced from local secure configuration and never embedded as plaintext secrets in export JSON.
- Schema version supports backward-compatible migration from current Modbus deployments.
