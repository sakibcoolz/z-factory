# TASK-1106 — Multi-Protocol Command Lifecycle & Safety

Status: **PLANNED**

Phase: **11 — Multi-Protocol PLC Connectivity**

## Objective

Route cloud commands through the selected PLC protocol while preserving the existing authorization, idempotency, expiry and PLC-authority rules.

## Requirements

- Command resolves logical tag -> selected adapter -> protocol mapping.
- Modbus uses the existing allowed write path.
- OPC UA uses Write only on explicitly exported writable nodes.
- Re-check expiry immediately before physical protocol write.
- Type/range/access validation occurs before adapter execution.
- Audit records retain logical tag identity and protocol outcome.
- No command may directly target an unapproved physical output mapping.
