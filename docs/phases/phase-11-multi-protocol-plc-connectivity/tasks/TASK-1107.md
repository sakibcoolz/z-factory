# TASK-1107 — UI, Observability, Migration & Mixed-Protocol E2E

Status: **PLANNED**

Phase: **11 — Multi-Protocol PLC Connectivity**

## Objective

Finish the user-visible and operational workflow and prove mixed-protocol operation end to end.

## Engineering UI

- PLC create/edit protocol selector.
- Protocol-specific configuration panels.
- Export preview/readiness for Modbus mappings or OPC UA NodeIds.
- LLM Context explains selected protocol and missing configuration.

## Edge/cloud observability

Show per PLC:
- protocol
- connection/session status
- last successful data timestamp
- reconnect/error counters
- subscription status for OPC UA or poll health for Modbus.

## Migration

Current Modbus JSON deployments remain valid or receive an explicit versioned migration path.

## E2E

One factory contains at least:
- PLC-A using Modbus TCP
- PLC-B using OPC UA

One Thin Client reads both simultaneously, publishes normalized MQTT telemetry, processes an authorized command for each protocol and demonstrates that failure/restart of one PLC does not stop the other.
