# TASK-1105 — Mixed-Protocol Worker Orchestration

Status: **PLANNED**

Phase: **11 — Multi-Protocol PLC Connectivity**

## Objective

Prove one Thin Client Agent can supervise Modbus TCP and OPC UA PLC workers concurrently in the same factory/site.

## Acceptance

- Add/remove/hot-reload PLC deployments without restarting unrelated workers.
- Modbus polling and OPC UA subscriptions run concurrently.
- Per-PLC backoff, reconnect and health are isolated.
- Agent limits/concurrency controls account for both protocol types.
- One protocol outage does not block MQTT publication from healthy PLCs.
- Offline spool/replay preserves normalized telemetry regardless of source protocol.
