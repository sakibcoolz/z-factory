# TASK-1101 — PLC Protocol Capability & Per-Instance Selection

Status: **PLANNED**

Phase: **11 — Multi-Protocol PLC Connectivity**

## Objective

Add communication capability metadata to PLC catalog profiles and let each factory PLC instance select its edge protocol independently.

## Requirements

- Supported protocol values: `MODBUS_TCP`, `OPC_UA`.
- Catalog declares which protocols a PLC model is known to support; unknown support is never invented.
- PLC create/edit flow exposes only supported choices.
- Existing PLCs default to their current Modbus behavior unless migrated explicitly.
- A factory may contain any supported mixture of protocol selections.
- LLM Context exposes selected protocol, alternatives and missing decisions.
