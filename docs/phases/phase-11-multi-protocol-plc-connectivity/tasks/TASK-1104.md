# TASK-1104 — OPC UA Client, Session & Subscription Runtime

Status: **PLANNED**

Phase: **11 — Multi-Protocol PLC Connectivity**

## Objective

Implement production OPC UA connectivity in the Go Thin Client Agent.

## Scope

- Endpoint connection and session lifecycle.
- Security policy/mode configuration.
- Certificate/trust handling suitable for unattended edge deployment.
- Explicit NodeId validation from deployment JSON.
- Subscriptions and monitored items for telemetry.
- Reconnect/session recovery and subscription re-creation.
- Typed value conversion into the normalized Thin Client model.
- Explicit OPC UA Write for authorized command/setpoint nodes only.
- Health and metrics for session state, subscription state, reconnects and data freshness.

No unrestricted browsing or auto-discovery is required for runtime operation.
