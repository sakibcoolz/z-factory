# TASK-1010 — Catalog Device Capability & Behavior Schema

Status: **PLANNED**

Phase: **10 — Agent-Ready Engineering & Full Catalog Go Simulation**

## Objective
Define the machine-readable behavior contract every simulatable catalog model uses.

## Schema concepts
Commands, feedback, parameters, units, ranges, states, timing, faults, latching/reset rules, quality, protocol behavior, relationship requirements and fidelity/coverage state.

## Acceptance criteria
- Catalog validation rejects impossible/incomplete simulator metadata.
- Generic and vendor-specific facts are clearly separated.
- A vendor profile never implies firmware emulation merely because its physical model exists.
