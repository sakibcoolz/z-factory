## Objective
Add an LLM Context tab to every active engineering page.

## Initial coverage

## Acceptance criteria
- Each active page exposes only context relevant to that page.
- Values and relationships match the normal UI.
- Sensitive secrets are never exposed.
- Context includes validation errors and available next actions.

## PR A — the PLC screens
### Implementation
- `components/plc/stored-plc-shell.tsx` takes `llmContext` and renders the panel after the screen's content: one place for all nine screens.
- `lib/agent/contexts/plc.ts`: `buildPlcContext({ factory, view, section, … })`. The common part comes from the `PlcConfigurationView` every screen loads: model and catalog record, architecture, runtime state, role, I/O occupancy and mapping versions; the wired devices with their wires, ports and rack modules as objects; "X is wired to PLC" with terminal → point as relationships; free channels per bank and free slots as capacity; the screen list, designer, simulator, live tags and events as navigation, without the screen itself. Each screen adds its own data, actions and issues: installable modules and the install/remove actions (hardware); the editor's starting point, stored versions, located variables and Check / Save version / Save & deploy, the last gated on a runtime (program); the versions with status, a failed version as an issue, Use for next start and Deploy now gated on a runtime (versions); the real state, container, Modbus TCP endpoint, programs, the last five events and Start, Deploy, Restart, Stop, Remove, Refresh state, each with its warning (runtime); peers, links with their health and a changed-since-deployed warning (communication); the export revision, mappings, program, snapshot and every download (export). Connections and I/O mapping say they are read-only and point to the designer.
- Kept out of the context: a link's server host and port (the page shows them; the context names the peer), the runtime's service name, container ids, ports of the management API, tokens.
- `lib/agent/contexts/registry.ts` adds `plc`, `program`, `plc-communication` and `export`; the LLM Index names them.
- Docs: `docs/design.md`, `docs/api-contract.md`, `docs/status.md`.
