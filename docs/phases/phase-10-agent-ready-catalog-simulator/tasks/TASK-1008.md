# TASK-1008 — Browser-Agent End-to-End Engineering Validation

Status: **PLANNED**

Phase: **10 — Agent-Ready Engineering & Full Catalog Go Simulation**

## Objective
Prove a browser-based agent can discover, recommend and apply an engineering change using only visible Z-Factory UI/context.

## Reference scenario
Create a tank, level sensor and pump; select compatible catalog models; confirm PLC capacity; create approved devices; wire compatible endpoints; validate; report the resulting design.

## Acceptance criteria
- No MCP/private database interface is used.
- Agent starts from Global LLM Index.
- Agent uses page-level LLM Context as it navigates.
- User decisions are requested where required.
- Final configuration passes normal Z-Factory validation.
