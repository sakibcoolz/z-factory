# TASK-1002 — Reusable Page-Level LLM Context Framework

Status: **PLANNED**

Phase: **10 — Agent-Ready Engineering & Full Catalog Go Simulation**

## Objective
Create one reusable LLM Context pattern for all active engineering pages.

## Required sections
- Page identity
- Current context
- Available objects/resources
- Current relationships
- Capacity/availability
- Validation state
- Available user actions
- Engineering constraints
- Missing decisions / recommended questions
- Navigation guidance

## Acceptance criteria
- All pages use the same semantic structure.
- Context is generated from current application data, not stale documentation.
- The component remains readable to humans while being predictable for browser agents.
