# AI Coding Agent Checklist

## Before work
- [ ] Read `AGENTS.md` and mandatory docs.
- [ ] Open active phase README.
- [ ] Open task Markdown and confirm status is READY/IN PROGRESS.
- [ ] Read linked Linear issue.
- [ ] Query Graphify for impacted code after graph exists.
- [ ] Confirm prerequisites/blockers.

## During work
- [ ] Stay inside task scope.
- [ ] Preserve compact/modular PLC invariants.
- [ ] Keep Docker/server-only code out of client bundle.
- [ ] Add tests.
- [ ] Update docs when contracts change.
- [ ] Avoid undocumented vendor assumptions.

## Before Done
- [ ] Lint/typecheck/tests pass.
- [ ] Acceptance criteria demonstrated.
- [ ] Task Markdown includes evidence/status.
- [ ] Linear issue updated.
- [ ] Graphify refreshed for structural changes.
- [ ] No secrets/generated junk committed.
