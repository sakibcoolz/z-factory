# PLC Source & Data Policy

## Authoritative sources
Prefer manufacturer product pages, equipment/system/hardware manuals, electrical/wiring manuals, module catalogs and official CAD metadata.

## Initial manufacturers
- Siemens: S7-1200 and S7-1500.
- Rockwell Automation: CompactLogix 5380.
- Schneider Electric: Modicon M241.

## Capture
Store normalized factual attributes plus:
- source URL;
- document/product title;
- document revision/version/date when available;
- page/section reference where useful;
- retrieval/verification date;
- verification status.

## Do not store by default
Full vendor manuals, proprietary firmware, engineering software, copyrighted imagery/CAD or trademarks as application assets unless licensing explicitly permits it.

## Verification
A catalog profile is not marked verified until its important electrical/I/O/communications/module compatibility facts are checked against authoritative documentation.
